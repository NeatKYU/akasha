# 블라인드 라벨링 시트 — r3

정답 키: `benchmarks/model-routing/answer-keys/r3.json` (먼저 키를 검토·확정한 뒤 라벨링 시작)
condition·배치는 가려져 있다. `blind-map.라벨링-끝나기-전-열지-말것.json`은 라벨링 완료 전까지 열지 않는다.

라벨링 방법 (응답마다):
1. **finding 표**: 응답의 finding마다 `매칭` 칸에 키 ID(예: r3-K1) / `FP`(키에 없고 잘못된 판정) / `중복`(같은 키를 이미 다른 finding이 커버) / `OK-기타`(키에 없지만 타당한 판정) 중 하나를 적는다.
2. **근거 적합성**: 그 finding이 인용한 knowledge_path·basis가 판정을 실제로 뒷받침하면 `적합`, 아니면 `부적합`, 판단 불가면 `불가`.
3. **키 커버리지**: 응답 전체를 보고 각 키 항목이 커버됐으면 체크(한 finding이 여러 키를 커버 가능, knowledge_gaps에서의 커버도 인정 — 키의 match_hint 참조).
4. **trap**: trap의 fp_signal이 응답에 나타나면 체크(= FP 발생).
