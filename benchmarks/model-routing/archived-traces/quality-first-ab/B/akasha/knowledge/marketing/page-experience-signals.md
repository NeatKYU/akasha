- 사용 메모: 페이지 경험 관련 주장의 범위 판정에만 사용한다.

## 이 문서가 해당 역할에 도움이 되는 이유

"페이지 경험을 개선하면 순위가 오른다"는 주장은 과장되기 쉽다. Google은 어떤 신호가
실제로 랭킹에 쓰이고 어떤 것이 그렇지 않은지, 그리고 점수 자체를 목표로 삼지 말라고
명시한다. 이 구분이 있어야 마케팅 제안의 과장을 지적할 수 있다.

## 프로젝트에 적용할 기준

- 페이지 경험 항목으로 Core Web Vitals, HTTPS, 모바일 표시, 방해되는 인터스티셜 회피, 광고 밀도를 함께 본다.
- 랭킹에 직접 쓰인다고 명시된 것은 Core Web Vitals다. 나머지는 사용자 만족을 높이지만 직접적인 순위 상승 근거로 제시하지 않는다.
- 단일 신호가 순위를 정하지 않는다. 제안은 "이 신호를 개선한다"로 쓰고 "순위가 오른다"로 쓰지 않는다.
- 주요 콘텐츠와 부가 콘텐츠가 시각적으로 구분되는지 확인한다.

## 주의할 점

- 보고서 점수가 좋아도 상위 노출이 보장되지 않는다고 Google이 명시한다.
- SEO만을 위해 만점을 목표로 하는 것은 시간 배분상 좋은 선택이 아닐 수 있다.
- 이 문서는 신호 목록과 범위를 다룬다. 임계값 수치는 Core Web Vitals 문서를 본다.

## 에이전트가 사용할 때의 체크리스트

- 제안이 "순위 상승"을 약속하고 있지 않은가?
- Core Web Vitals 외 항목을 직접적 랭킹 요인으로 제시하고 있지 않은가?
- HTTPS, 모바일 표시, 인터스티셜, 광고 밀도가 함께 검토되었는가?
- 점수 만점 자체를 목표로 삼고 있지 않은가?
