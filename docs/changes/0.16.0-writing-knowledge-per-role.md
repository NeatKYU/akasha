# 0.16.0+ — 작가 역할 7개에 지식 카드를 역할당 10장으로

2026-08-25 · 지식 문서 83 → 142 (+59)

## 한 줄 요약

역할당 1~3장이던 작가 도메인 카드를 **역할당 10장**으로 채웠다. 출처 59개를 전부 `pin:source`로
고정하고(부채 0), 카드는 역할별 서브에이전트 7개가 원문을 실제로 읽고 썼으며, 부모가 절 이름·스냅샷
줄·권위·사용 메모 문구·길이를 manifest와 기계 대조한 뒤 역할 문서와 INDEX에 연결했다.

## 이전에는

| 역할 | 카드 |
| --- | --- |
| worldbuilding 3 · style 2 · character 1 · plot 1 · staging 1 · continuity 1(+공유 1) · reader 1 | 10 |

primary는 style 2장뿐. plot·staging·reader는 카드 1장으로 판정 범위가 사실상 훅·구조·장면 한 가지였다.

작성 절차(재사용 가능): 부모가 출처 탐색·허용 호스트·pin을 중앙에서 하고 manifest(역할·id·URL·파일·소유자·권위·
스냅샷 줄)를 만든 뒤, 역할별 서브에이전트가 원문을 가져와 읽고 카드를 쓴다. 부모는 `wire-cards.mjs`로
59장을 검사(5개 절·스냅샷·id·URL·권위·secondary 문구·25~70줄·힌트)하고 역할 문서 `## 담당 지식`과 INDEX에
넣는다. 7개 에이전트 합계 약 785k 토큰, 벽시계 약 9.5분(병렬).

## 대가

- 작가 역할 on-invoke +0.5k씩. 카드가 늘수록 선택 힌트 목록이 길어지는 구조라, 도메인당 카드 20장을
  넘기면 힌트를 별도 파일로 빼는 설계를 검토해야 한다.
- 출처 다양성이 낮다. 59장 중 49장이 K.M. Weiland 한 사이트다. 정적 HTML·소유자 사이트·허용 호스트
  조건을 동시에 만족하는 작법 출처가 드물어서다(law.go.kr·문피아·카카오 스테이지는 JS 렌더링, kornorms는
  접속 불가). 한국어 작법·플랫폼 규정 출처가 비어 있다.
- 한글 맞춤법(띄어쓰기·문장 부호)은 여전히 없다. korean.go.kr page_id 1~460 범위에 없다.

## 미검증

- 카드 내용의 정확성은 서브에이전트가 원문을 읽고 썼다는 것과 구조 검사까지만 확인했다. 사람 검토
  전이며, 특히 primary 8장은 조문 해석이 판정 근거가 되므로 사람이 한 번 봐야 한다.
- 역할당 10장일 때 부모의 `selected_knowledge_paths` 선택 정확도. fixture 없음.
