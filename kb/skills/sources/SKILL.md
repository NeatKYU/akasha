# 지식베이스 출처 조회

서브에이전트 없이 직접 조회한다.

`<플러그인 루트>` 결정: `${CLAUDE_PLUGIN_ROOT}` 가 실제 경로로 치환되어 있으면 그
경로를 쓴다. 치환되지 않았으면 이 스킬 파일(`skills/sources/SKILL.md`)이 설치된
위치의 두 단계 위 디렉터리를 쓴다.

## 절차

1. `<플러그인 루트>/knowledge/INDEX.md` 를 읽는다.
2. 사용자가 역할이나 주제를 지정했으면 해당 지식 문서만, 지정하지 않았으면 전체
   문서의 `## 출처` 절을 읽는다.
3. 문서별로 다음을 표로 정리한다:
   - 문서 제목과 경로
   - 출처 URL, 소유자, 권위(primary/secondary)
   - 사용 메모(허용 목적)
4. 플러그인 버전을 함께 보고한다 (`<플러그인 루트>/.claude-plugin/plugin.json` 또는
   `.codex-plugin/plugin.json` 의 `version`). 이 버전이 설치된 승인 스냅샷의
   기준 시점이다.

## 안전 규칙

- 출처 URL을 조회 요청 없이 fetch하지 않는다. 이 스킬은 로컬 문서 조회 전용이다.
- secondary 출처는 영감·사례용이며 규범적 결론의 근거가 아니라는 점을 표시한다.
